# 04. Local LLM 연구 Reference

이 폴더는 My Planner의 Local LLM 설계와 실험 결과를 해석할 때 참고한 논문과 연구 근거를 정리한다.

## 현재 문서

- [bias-concepts/BIAS_CONCEPTS_OVERVIEW.md](bias-concepts/BIAS_CONCEPTS_OVERVIEW.md): 네 가지 few-shot bias를 동일한 형식으로 비교하는 입문 가이드
- [few-shot-demonstration-copy-bias.md](few-shot-demonstration-copy-bias.md): Few-shot 예시 값 복사, demonstration bias와 prompt 민감성

## 읽는 순서

1. 먼저 [Few-shot Bias 개념 가이드](bias-concepts/BIAS_CONCEPTS_OVERVIEW.md)에서 네 개념의 차이를 파악한다.
2. 이후 [논문 근거 중심 상세 문서](few-shot-demonstration-copy-bias.md)에서 연구별 근거와 My Planner 적용 해석을 확인한다.

## 문서 작성 원칙

- 논문 원문, 학회 Proceedings와 공식 학술 저장소를 우선한다.
- 논문이 직접 증명한 내용과 My Planner 실험에 대한 해석을 구분한다.
- 한 번의 모델 출력만으로 일반적인 인과관계를 확정하지 않는다.
- Preprint와 peer-reviewed conference paper의 상태를 구분한다.
- 실제 제품 대응 방안은 현재 제약과 평가 결과에 맞춰 별도로 판단한다.
